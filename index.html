Syntax reference

@startlean               ' pick a canvas: lean, bmc, vpc, swot, empathy, roam, lbc, ia, ddd, story
title  My Startup        ' header lines: title, subtitle, author, date, version
theme  blueprint         ' light, dark, blueprint or mono

problem {                ' a block: section name { ... }
  - First problem
  - Second problem #red  ' end an item with a color tag
}

uvp: One clear sentence  ' or a one-line section
' this is a comment
@endlean
  • Items start with -, * or +. Plain lines inside a block also count as items.
  • Colors: #yellow #green #blue #pink #orange #purple #gray #red or hex like #f80.
  • A block opens with problem { and closes with }. The older problem ... end form still works.
  • Repeat a section to add more items; they are merged. Section names ignore case and spaces.
  • Comments start with ' or //; /' ... '/ spans lines.
